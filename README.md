# Acquisti Mediateca

Lanciatore dell'app «Acquisti Mediateca» (Mediateca LGBT e Queer · ARC).

Questa pagina serve solo a installare l'app sul telefono con il logo come icona:
apre l'app web di Google Apps Script collegata al foglio «Acquisti Mediateca».
I dati restano nel foglio Google e sono visibili solo a chi vi ha accesso con il proprio account.

- Android (Chrome): menu ⋮ → Installa e crea scorciatoia → Installa
- iPhone (Safari): Condividi → Aggiungi alla schermata Home
